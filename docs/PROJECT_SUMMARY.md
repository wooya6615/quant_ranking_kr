# PROJECT SUMMARY -- 랭킹 objective 전환 실험

## 배경

`quant_xgboost`에서 XGBoost 이진분류(오를지/내릴지)로 개별 종목을 독립적으로 평가했을 때,
BASE/COMBINED 둘 다 거래비용 반영 후 Buy & Hold를 이기지 못하는 구조적 한계가 있었음.
이 한계가 "예측 정확도" 문제가 아니라 "문제 설정(방향 예측)" 자체의 한계일 수 있다는
가설 아래, 문제를 "오늘 여러 종목 중 뭘 살지" 랭킹 문제로 바꿔서 LightGBM `lambdarank`로
재검증함. feature는 quant_xgboost와 동일한 BASE 13개(가격/거래량 파생)만 사용 --
그래야 성능 차이가 순수하게 "이진분류 -> 랭킹 objective 전환 효과"인지 확인 가능.

## 실험 설계

- 유니버스: KOSPI 시가총액/구성종목 기준 50종목 풀 (`build_pool.py`)
- 평가: 매일 랭킹 점수 상위 top_k(=5) 종목의 평균 `future_return`(10일 후 수익률)을
  (a) 이진분류로 확률 상위 뽑는 방식, (b) 동일가중(전 종목 균등 매수) baseline과 비교
- 검증: 날짜 기준 walk-forward, 5-seed(42/1/7/123/2024), 거래비용 왕복 0.2% 반영

## 결과 요약

| 검증 단계 | 결과 | 판정 |
|---|---|---|
| 5-seed 일관성 (gross) | `rank_vs_equal_weight`, `rank_vs_binary` 모두 5/5 양수 | 통과 |
| 거래비용 반영 (net) | 위 결과 net으로도 5/5 양수 유지 | 통과 |
| 국면 집중도 (연도별) | 2024~2025 두 해가 전체 edge의 **97%** 차지 (11개 연도 중) | **실패** |
| 국면 제외 재검증 | 2024~25 제외 시 `rank_vs_equal_weight_net`은 5/5 양수 유지되나 0.01~0.07%p로 사실상 0에 수렴. `rank_vs_binary_net`은 **4/5 음수로 반전** | **실패** |
| 코스피 방향성 상관 | edge vs 코스피 연간수익률 상관계수 **-0.064** (사실상 무관) | 가설 기각 |
| 종목 단위 분해 | 상위 5종목이 전체 edge의 **109.7%** 차지 (나머지 45종목 순기여 음수) | **핵심 원인 확인** |

## 핵심 발견

edge에 기여한 상위 종목은 대부분 2024~2025 한국 증시의 3대 테마(전력기기/변압기,
K-방산, 조선)에 쏠려 있었음 (한화에어로스페이스, LIG넥스원, 효성중공업, LS ELECTRIC,
HD현대일렉트릭, 삼성중공업, 한화오션, HD현대마린솔루션 등). BASE 피처가 대부분
모멘텀 계열(`return_20d`, `macd_hist` 등)이라, 이 테마들이 수개월~1년씩 지속적으로
상승하는 동안 추세추종이 우연히 잘 맞아떨어진 것으로 보임 -- 일반적인 종목 선별
능력이 아니라 특정 시기 특정 테마의 모멘텀을 반복 포착한 결과.

## 결론

**"XGBoost 이진분류를 LightGBM 랭킹 objective로 바꾸면 나아지는가?"라는 원래 질문에는
일반적으로 "아니오"에 가까움.** 표면적으로 나아진 것처럼 보였던 결과는 2024~2025
특정 테마주 몇 개를 우연히 포착한 것이었고, 그 두 해를 빼면 원래 가설(랭킹이
이진분류보다 낫다)의 근거였던 `rank_vs_binary` 우위는 사실상 사라지거나 반전됨.

quant_xgboost의 밸류에이션 실험(모트렉스 74.9%가 2020년 한 해 집중, 한전기술은
2021년 집중)과 같은 패턴이 다시 확인된 것 -- "5-seed 일관성"은 랜덤성에 대한
방어일 뿐, 국면/종목 집중 문제에 대해서는 아무 방어도 되지 않는다는 게 이 프로젝트
전체에서 반복적으로 나타나는 교훈.
